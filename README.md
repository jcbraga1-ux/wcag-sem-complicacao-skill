# WCAG sem complicação – Skill

Agent Skill com os **78 critérios de sucesso da WCAG 2.1** explicados em linguagem simples, cada um com um exemplo prático do sistema fictício da UBS Jardim Esperança. Funciona com assistentes de IA compatíveis com o padrão aberto [Agent Skills](https://agentskills.io/).

As Diretrizes de Acessibilidade para Conteúdo Web (WCAG) dizem o que um site ou aplicativo precisa ter para que pessoas com deficiência consigam usá-lo. A skill organiza a norma em 4 princípios, 13 diretrizes e 78 critérios, nos níveis A, AA e AAA.

## O que a skill faz

- **Consulta:** “O que diz o critério 1.4.3 da WCAG?”
- **Auditoria:** avalia um site, app ou protótipo pelos 50 critérios A + AA (atende / não atende / não se aplica), com as falhas priorizadas.
- **Requisitos:** transforma critérios em requisitos de um projeto, com critério de aceitação.
- **Ensino:** explica cada princípio e critério em linguagem simples, com exemplos.

## Como instalar

A skill é a pasta [`wcag-sem-complicacao/`](wcag-sem-complicacao/), com o arquivo `SKILL.md`.

- **Assistentes com tela de configurações:** compacte a pasta `wcag-sem-complicacao` em um arquivo `.zip` e envie na seção de Skills.
- **Ferramentas que leem skills de uma pasta:** copie a pasta `wcag-sem-complicacao` para o diretório de skills indicado na documentação da ferramenta.

Depois de instalada, basta pedir em linguagem natural, por exemplo: *“Avalie esta tela com a WCAG no nível AA.”*

## Fonte e créditos

Baseado em: W3C. **Web Content Accessibility Guidelines (WCAG) 2.1**. Recomendação do W3C. Disponível em: https://www.w3.org/TR/WCAG21/.

As explicações simplificadas e os exemplos da UBS Jardim Esperança foram elaborados para a disciplina de Interação Humano-Computador da **Universidade Federal do ABC (UFABC)**, no grupo de pesquisa **INTERA**. Elas são simplificações didáticas: para avaliar um sistema formalmente, consulte o texto oficial de cada critério.

A skill traz uma nota sobre a **WCAG 2.2** (critério 4.1.1 obsoleto e os 9 critérios novos), sem detalhá-los.
